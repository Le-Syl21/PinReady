Transferir o PinReady

O PinReady é um único ficheiro de programa: transfira o do seu sistema, extraia-o e inicie-o. Não há nada para instalar. Estas ligações apontam sempre para a versão mais recente.

Notas de versão e versões anteriores: todas as versões no GitHub.

Iniciar

  • Windows: extraia o zip e faça duplo clique em pinready.exe.
  • Linux: extraia o arquivo e inicie o programa a partir da respetiva pasta: 
    tar xzf pinready-linux-x86_64.tar.gz ./pinready
  • macOS: extraia o arquivo e inicie o programa a partir do Terminal: 
    tar xzf pinready-macos-aarch64.tar.gz ./pinready

O programa para Windows tem assinatura digital, e os programas para macOS são assinados e notarizados pela Apple. As versões para macOS destinam-se ao macOS 11 ou posterior.

O primeiro arranque abre o assistente de configuração; os seguintes abrem o lançador de mesas.

O que é preciso

  • Visual Pinball X 10.8.1 ou posterior. O PinReady pode instalá-lo por si, ou usar uma cópia que tenha instalado por conta própria.
  • Uma pasta de mesas com a organização da 10.8.1, uma pasta por mesa. O PinReady pode ajudar a chegar lá: veja a página Mesas do assistente.
  • Uma ligação à Internet para a instalação automática do Visual Pinball e para a verificação de atualizações. É opcional se instalar o Visual Pinball por conta própria.

Não há bibliotecas para instalar: o SDL3 e o SQLite estão integrados no PinReady.

Instalar o Visual Pinball

A primeira página do assistente propõe duas opções:

  • Instalar automaticamente (recomendado) transfere e instala uma versão recente do fork do Visual Pinball X testado com o PinReady, a partir de Le-Syl21/vpinball. Esta não é a versão oficial do VPX. Escolhe a versão certa para o seu sistema, incluindo versões para placas Raspberry Pi e RK3588 em Linux ARM. Você escolhe a pasta de instalação.
  • Já tenho o Visual Pinball usa uma cópia que instalou por conta própria: indique ao PinReady o programa VPinballX_BGFX.

A instalação automática é testada no Ubuntu 24.04 e 26.04 LTS (GNOME) e no Windows 11, com 4 ecrãs. O projeto oficial do Visual Pinball está em vpinball/vpinball.

Atualizações

No arranque, o PinReady verifica se saiu uma nova versão do Visual Pinball ou do PinReady. Quando sai, aparece um botão de atualização no lançador: um clique transfere-a e instala-a.

Compilar a partir do código-fonte

O PinReady é escrito em Rust. No Linux (Debian ou Ubuntu), instale primeiro as ferramentas de compilação:

sudo apt install build-essential cmake pkg-config \
  libxcb-render0-dev libxcb-shape0-dev libxcb-xfixes0-dev \
  libxkbcommon-dev libssl-dev

cargo build --release

No macOS e no Windows, cargo build --release é suficiente. O SDL3 e o SQLite são compilados automaticamente a partir do código-fonte. O programa fica em target/release/.
