PinReady のダウンロード

PinReady はプログラムファイルがひとつだけです。お使いのシステム用のものをダウンロードして展開し、起動してください。インストールは必要ありません。これらのリンクは常に最新リリースを指します。

システムダウンロード
Linux
Intel または AMD の 64ビットプロセッサーを搭載した PC（x86_64）		pinready-linux-x86_64.tar.gz
Linux
ARM 64ビットプロセッサー（aarch64）		pinready-linux-aarch64.tar.gz
macOS
Apple シリコンの Mac（M シリーズのチップ）		pinready-macos-aarch64.tar.gz
macOS
Intel の Mac		pinready-macos-x86_64.tar.gz
Windows
64ビットの Windows PC（x86_64）		pinready-windows-x86_64.zip

リリースノートと過去のバージョン：GitHub のすべてのリリース。

起動のしかた

  • Windows：zip を展開し、pinready.exe をダブルクリックします。
  • Linux：アーカイブを展開し、そのフォルダーからプログラムを起動します。
    tar xzf pinready-linux-x86_64.tar.gz ./pinready
  • macOS：アーカイブを展開し、ターミナルからプログラムを起動します。
    tar xzf pinready-macos-aarch64.tar.gz ./pinready

Windows 用プログラムにはデジタル署名が付いています。macOS 用プログラムは署名済みで、Apple の公証も受けています。macOS 版は macOS 11 以降が対象です。

初回の起動ではセットアップウィザードが開き、2回目以降はテーブルランチャーが開きます。

必要なもの

  • Visual Pinball X 10.8.1 以降。PinReady がインストールすることも、ご自身でインストールしたものを使うこともできます。
  • 10.8.1 のレイアウトに沿ったテーブルフォルダー（テーブルごとに1フォルダー）。PinReady がそこまでの作業を手伝います。ウィザードのテーブルのページをご覧ください。
  • インターネット接続：Visual Pinball の自動インストールと更新の確認に使います。Visual Pinball を自分でインストールする場合は、なくてもかまいません。

インストールが必要なライブラリはありません。SDL3 と SQLite は PinReady に組み込まれています。

Visual Pinball のインストール

ウィザードの最初のページには、2つの選択肢があります。

  • 自動でインストール（おすすめ）：PinReady で動作確認をした Visual Pinball X のフォーク（Le-Syl21/vpinball）の最近のビルドをダウンロードしてインストールします。これは公式の VPX ビルドではありません。システムに合ったビルドが選ばれ、ARM の Linux では Raspberry Pi や RK3588 ボード向けのビルドも含まれます。インストール先のフォルダーは自分で選べます。
  • Visual Pinball はすでに持っている：ご自身でインストールしたものを使います。PinReady に VPinballX_BGFX プログラムの場所を指定してください。

自動インストールは、Ubuntu 24.04 と 26.04 LTS（GNOME）、および Windows 11 で、4画面の構成を使って動作確認しています。公式の Visual Pinball プロジェクトは vpinball/vpinball にあります。

更新

起動時に、PinReady は Visual Pinball の新しいビルドや PinReady の新しいバージョンが出ていないかを確認します。出ているときは、ランチャーに更新ボタンが表示され、1クリックでダウンロードとインストールができます。

フォルダーは自動的に見つかるので、自分で作る必要はありません。

ソースからビルドする

PinReady は Rust で書かれています。Linux（Debian または Ubuntu）では、まずビルドツールをインストールしてください。

sudo apt install build-essential cmake pkg-config \
  libxcb-render0-dev libxcb-shape0-dev libxcb-xfixes0-dev \
  libxkbcommon-dev libssl-dev

cargo build --release

macOS と Windows では、cargo build --release だけで十分です。SDL3 と SQLite はソースから自動的にコンパイルされます。完成したプログラムは target/release/ に置かれます。
