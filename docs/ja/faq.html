質問と回答

PinReady と Visual Pinball X 10.8.1 スタンドアロンについてのよくある質問です。載っていないことがあれば、Discord で聞いてください。

PinReady は私のキャビネットに向いていますか？

PinReady は、Visual Pinball X 10.8.1 の開発と普及を支えるために作られています。対象は、新しい 10.8.1 の仕組み（統合プラグイン、テーブルごとに1フォルダー、SDL3/bgfx エンジン）を試すテスターやアーリーアダプターです。頼りにしている安定版の VPX 10.7.x 構成でキャビネットを動かしている場合は、今のところ PinReady は向かない可能性があります。

本物のピンボール台が必要ですか？

いいえ。ウィザードは画面1つから始められます。通常のパソコンなら 1画面とデスクトップ表示モードを選び、キーボードかゲームパッドで遊んでください。2〜4画面、ピンボール用コントローラーボード、加速度センサー、サラウンドサウンドは、どれも任意です。

PinReady は公式の Visual Pinball をインストールしますか？

いいえ。自動インストールでは、PinReady で動作確認をした Visual Pinball X のフォーク（Le-Syl21/vpinball）の最近のビルドをダウンロードします。公式の VPX ビルドではありません。ご自身のインストールを使いたい場合は、最初のページでVisual Pinball はすでに持っているを選び、PinReady に VPinballX_BGFX プログラムの場所を指定してください。

どのピンボール用コントローラーボードに対応していますか？

Pinscape KL25Z（KL Shield V5.1、Brain、Rig Master）、Pinscape Pico、DudesCab、CSD PinOne です。検出されると、出荷時のボタン配置がジョイスティックの列に入力され、プランジャーと加速度センサーは VPX が自動的に処理します。ほかのジョイスティックやゲームパッドも使えます。ボタンを1つずつ割り当ててください。ウィザードの入力のページをご覧ください。

古いテーブルが VPX スタンドアロンで動きません。どうすればよいですか？

古いテーブルの中には、Windows でしか動かない VBScript の機能を使っているものがあります。テーブルのページで、自動 VBS パッチをオンにしてください。Le-Syl21/vpx-standalone-scripts にパッチがあれば、PinReady がパッチ適用済みのスクリプトをテーブルの隣に置きます。パッチによって特定のテーブルがかえって悪くなることがまれにあるため、初期設定ではオフです。手作業でもできます。jsm174/vpx-standalone-scripts からお使いのテーブルに合う .vbs を取り出し、.vpx と同じベース名にして、その隣に置いてください。

1つのテーブルだけ別の設定にするには？

.vpx の隣に、同じベース名の .ini ファイルを置き、変更したい設定だけを書いてください。そのほかの設定は、グローバルな VPinballX.ini から読み込まれます。これらの設定をテーブルファイルの中に持たせたい場合は、vpxtool でテーブルを展開し（vpxtool extract MyTable.vpx）、ini を含めて組み立て直せます（vpxtool assemble MyTable/）。

テーブルがディスクの容量を大きく使います。

テーブルには、大きな可逆圧縮の画像が入っていることがよくあります。vpxtool を使うと、それらを WebP に変換できます：vpxtool images webp MyTable.vpx。

トイ、ライト、ソレノイドがゲーム中に何も動きません。

Visual Pinball は、DOF を含むすべてのプラグインをオフにした状態で出荷されます。VPUniverse ConfigTool で DOF の設定を生成し、directoutputconfig フォルダーに展開してから、アクセサリーのページで DOF をオンにしてください。

何もしていないのにテーブルがティルトする、またはまったくティルトしません。

ティルト / ナッジのページで加速度センサーの範囲を確認してください。お使いのボードが実際に使っている範囲と一致している必要があります。ボードが範囲を公開している場合、PinReady はボードから読み取り、選んだ値が合っていなければ警告します。範囲が間違っていると、どの揺れも強すぎたり弱すぎたりして見え、ほかの設定では補えません。選んだティルト角がセンサーの届く範囲を外れているときも、このページでお知らせします。

音が違うスピーカーから出ます。

音声のページのテストを使ってください。転がるボールが前後で逆に動く場合は出力モードを変更し、左右で逆に動く場合は左右の配線を確認してください。ジャックの色はサウンドカードによって異なります。

Linux：アクセサリーのページで出力ボードが見つかりません。

Linux で USB HID に直接アクセスするには、たいてい udev ルールが必要です。アクセサリーのページにルールが表示され、コピーしたり、パスワードを入力したうえで代わりにインストールしたりできます。

Linux：Wayland と X11 を切り替えたあと、ウィザードをやり直す必要はありますか？

いいえ。Visual Pinball が Wayland で動くか X11 で動くかによって画面の名前が変わるため、PinReady は各画面を、位置、サイズ、EDID の識別情報（モニターが報告する ID）で覚えています。ランチャーの起動時に、VPX が使うドライバーを選び、VPinballX.ini の画面名をそれに合わせて更新します。

設定をやり直すにはどうしますか？

ランチャーの設定ボタンからウィザードを開くか、pinready --config を実行します。最初からやり直したい場合は、ウィザードの設定をリセットを使ってください。すべての回答が破棄され、以前の VPinballX.ini は VPinballX.ini.reset-backup として残されます。テーブルには手を付けません。

Visual Pinball がクラッシュしました。どう報告すればよいですか？

VPX が異常終了すると、PinReady は、クラッシュを再現するコマンド、システム情報、ログ、クラッシュダンプの場所を載せたレポートを表示します。コピーか保存…をクリックして、Discord か GitHub の課題で共有してください。

ランチャーでテーブルに「画像なし」と表示されます。

テーブルフォルダーの medias/launcher.png に画像を置いてください（.webp、.jpg、.jpeg も使えます）。.directb2s のバックグラスファイルでもかまいません。テーブルを整理し直したあとで画像が古いままのときは、ランチャーで再構築をクリックしてください。

設定はどこに保存されますか？

ファイルの保存場所をご覧ください。pinready --print-paths を実行すると、PinReady が実際に使っているパスが表示されます。
