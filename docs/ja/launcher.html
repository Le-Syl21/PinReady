テーブルランチャー

ウィザードが終わると、PinReady はそのままテーブルの画面に切り替わります。テーブルを選んで起動し、Visual Pinball を閉じると一覧に戻ります。

テーブルを探す

  • テーブルフォルダーにあるすべてのテーブルフォルダーがグリッドで表示され、それぞれにバックグラスの画像が付きます。画像は、テーブルの .directb2s ファイル、カタログの補完でダウンロードしたアートワーク、またはご自身の medias/launcher.png から取られます。
  • 検索：文字を入力し始めるだけで、入力に合わせて一覧が絞り込まれます。
  • Virtual Pinball Spreadsheet により新しいバージョンが掲載されているテーブルには更新ありのバッジが付きます。VPinPlay をオンにしていれば、コミュニティの評価も表示されます。どちらもスキャン中に再起動なしで表示され、テーブルのデータベースは起動時と6時間ごとに自動で更新されます。
  • 再構築：キャッシュされた画像とスクリプトパッチの状態を消去し、テーブルフォルダーをもう一度スキャンします。一覧がディスクの内容と合わなくなったときに使います。
  • ツールバーには、ウィザードを開き直す設定ボタン、ライト/ダークのテーマ切り替え、回転ボタン、バージョン情報ボックスもあります。

操作

ジョイスティックのボタンは、ウィザードで設定した割り当てに従うので、キャビネットのボタンはランチャーでもそのまま使えます。

複数画面のキャビネットでは

キャビネット表示モードでは、ランチャーはプレイフィールドの画面に全画面で開き、平らに寝かせた画面に合わせて回転し、マウスポインターは PinReady が描画します。ほかの画面も使われます。

  • バックグラス：選択中のテーブルのバックグラスの画像。
  • DMD とトッパー：Visual Pinball のロゴと、選択中のテーブルの詳細（名前、メーカーと発売年、作者、バージョン、日付、遊んだ回数、あなたの評価）を載せたカバー。

テーブルが起動すると、これらのカバーは脇にどいて、Visual Pinball がすべての画面を引き継げるようになります。

テーブルを起動する

テーブルの読み込み中は、Visual Pinball が報告する進捗が読み込みオーバーレイに表示されます。Linux では、PinReady がデスクトップセッションに合わせて Visual Pinball が動作するディスプレイドライバー（Wayland か X11）を選び、VPinballX.ini の画面名もそれに合わせて更新するので、各ウィンドウが正しい画面に開きます。

Visual Pinball がクラッシュしたとき

Visual Pinball が異常終了すると、PinReady は黙って一覧に戻るのではなく、レポートを表示します。内容は、問題を再現するコマンド、作業フォルダー、システム情報、読み込みログ、ゲームログの最後の100行、そしてお使いのシステム上のクラッシュダンプの正確な場所（Linux では systemd-coredump、macOS では ~/Library/Logs/DiagnosticReports/、Windows では %LOCALAPPDATA%\CrashDumps\）です。コピーを押すとクリップボードに入り、そのまま不具合の報告に使えます。保存…を押すとファイルに書き出します。

更新

PinReady は、起動時に Visual Pinball と PinReady 自身の新しいバージョンを確認します。更新ボタンはランチャーに表示され、1クリックでインストールできます。最初の起動では、セットアップを始める前に新しい PinReady を案内するので、最新の修正を取り込んだ状態ですべてを設定できます。設定をリセットしても Visual Pinball のインストールは残るため、すでに入っているビルドへの更新を案内することはありません。

コマンドラインのオプション

オプション動作
--config, -cセットアップウィザードを開きます。
--reset-wizardウィザードを未完了としてマークして終了します。次回の起動ではウィザードに戻ります。
--merge-dry-run SCAN_ROOT [OUTPUT] [--strategy MODE]コレクションのインポートで何がどこに置かれるかを、ファイルには一切手を付けずに表示します。
--merge SCAN_ROOT [OUTPUT] [--strategy MODE] [--yes]インポートを実行します。MODE は copy（初期設定）、move、symlink のいずれかです。コレクションがすでにテーブルごとに1フォルダーになっている場合は、OUTPUT を省略してください。
--print-pathsデータベース、ログ、ini、テーブル、Visual Pinball のパスを表示します。
--list-tables見つかったテーブルフォルダーごとに1行ずつ表示します。
--version, --helpバージョンとライセンス、またはヘルプを表示します。
