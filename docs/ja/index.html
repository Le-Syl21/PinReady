Visual Pinball X 10.8.1 スタンドアロン

バーチャルピンボールをセットアップして、さっそく遊ぼう

PinReady は、Visual Pinball X (VPX) 10.8.1 スタンドアロン向けの、無料のオープンソースのセットアップウィザード兼テーブルランチャーです。画面、操作系、ティルトとナッジ、サウンドをやさしい言葉で設定し、ひとつのメニューからテーブルを探して起動できます。画面が1つのパソコンから、複数の画面を備えた本格的な pincab（ピンボール台型のキャビネット）まで、Linux、macOS、Windows で使えます。

PinReady をダウンロード 動画を見る（フランス語）

対象範囲について。インストール前にお読みください。PinReady は VPX 10.8.1 の開発と普及を支えるためのもので、安定して動いている本番環境の置き換えを目的としたものではありません。対象は、新しい 10.8.1 の仕組み（統合プラグイン、テーブルごとに1フォルダー、SDL3/bgfx エンジン）を試すテスターやアーリーアダプターです。安定版の VPX 10.7.x でキャビネットを運用中の方には、今のところ向かない可能性があります。

PinReady を選ぶ理由

Visual Pinball X のスタンドアロン版には、専用の設定ツールがありません。画面、ボタン、スピーカーの設定は、テキストファイル VPinballX.ini の中の行として書かれています。PinReady は代わりに質問を投げかけ、ハードウェアを検出して、そのファイルを書き込みます。ファイル内のコメントもそのまま残します。ウィザードが終わると、PinReady はそのままテーブルコレクションの画面に切り替わります。

PinReady がお世話すること

  • Visual Pinball 本体：お使いのシステム向けの VPX ビルドをダウンロードしてインストールします。すでにお持ちのものを使うこともでき、新しいビルドが出ると更新を知らせます。
  • 画面：すべてのディスプレイを検出し、どれをプレイフィールド、バックグラス（奥に立っている縦長の画面）、DMD（スコア表示用の画面）、トッパーにするかを提案して、ゲームのウィンドウを配置します。
  • 操作系：VPX のすべての操作にキーボードとジョイスティックを割り当てられます。Pinscape KL25Z、Pinscape Pico、DudesCab、PinOne の各ボード用のレイアウトが用意されており、2つの操作に同じキーを割り当てると警告が出ます。
  • ティルトとナッジ：加速度センサーの感度を、キャビネットを揺らしながらリアルタイム表示で調整できます。
  • サウンド：音楽と音声用のサウンドカード、プレイフィールドの機械音用のサウンドカードをそれぞれ選べます。SSF（サラウンドサウンドフィードバック）を含む6種類のスピーカー配置に対応し、配線を確かめるテスト音も鳴らせます。
  • テーブル：テーブルフォルダー、各テーブルを専用フォルダーに整理するオプションのインポート、古いテーブル向けのオプションのスクリプトパッチ、ランチャー用にダウンロードするバックグラスの画像。
  • アクセサリー：DOF（Direct Output Framework：トイ、ライト、ソレノイドの制御）のステップバイステップの案内と、ワンクリックでのヘッドトラッキングのインストール。
  • システム：起動時の自動スタート、メニューのショートカット、そして .vpx ファイルを Visual Pinball で開く設定。

対応環境

  • Linux（x86_64 と ARM 64ビット）、macOS（Apple シリコンと Intel、macOS 11 以降）、Windows（64ビット）。
  • システム側の依存関係はありません。SDL3 と SQLite はプログラムに組み込まれています。
  • インターフェースは英語とフランス語を含む26言語に対応しています。
