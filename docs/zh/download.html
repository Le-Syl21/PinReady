Ladda ner PinReady

PinReady är en enda programfil: ladda ner den som passar ditt system, packa upp den och starta den. Det finns inget att installera. De här länkarna pekar alltid på den senaste utgåvan.

Versionsanteckningar och äldre versioner: alla utgåvor på GitHub.

Starta det

  • Windows: packa upp zip-filen och dubbelklicka sedan på pinready.exe.
  • Linux: packa upp arkivet och starta programmet från dess mapp: 
    tar xzf pinready-linux-x86_64.tar.gz ./pinready
  • macOS: packa upp arkivet och starta programmet från Terminalen: 
    tar xzf pinready-macos-aarch64.tar.gz ./pinready

Windows-programmet är digitalt signerat, och macOS-programmen är signerade och notariserade hos Apple. macOS-versionerna riktar sig till macOS 11 eller senare.

Första starten öppnar installationsguiden; följande starter öppnar bordsstartaren.

Vad du behöver

  • Visual Pinball X 10.8.1 eller senare. PinReady kan installera det åt dig, eller använda en kopia som du själv har installerat.
  • En bordsmapp med layouten från 10.8.1, en mapp per bord. PinReady kan hjälpa dig dit: se sidan Bord i guiden.
  • En internetanslutning för den automatiska installationen av Visual Pinball och för uppdateringskontroller. Den är valfri om du installerar Visual Pinball själv.

Det finns inga bibliotek att installera: SDL3 och SQLite är inbyggda i PinReady.

Installera Visual Pinball

Guidens första sida erbjuder två val:

  • Installera automatiskt (rekommenderas) laddar ner och installerar en ny version av den Visual Pinball X-fork som testats med PinReady, från Le-Syl21/vpinball. Det är inte den officiella VPX-versionen. Den väljer rätt version för ditt system, även versioner för Raspberry Pi och RK3588-kort på ARM-Linux. Du väljer installationsmapp.
  • Jag har redan Visual Pinball använder en kopia som du själv har installerat: peka PinReady på programmet VPinballX_BGFX.

Den automatiska installationen är testad på Ubuntu 24.04 och 26.04 LTS (GNOME) och på Windows 11, med 4 skärmar. Det officiella Visual Pinball-projektet finns på vpinball/vpinball.

Uppdateringar

Vid start kontrollerar PinReady om det finns en ny version av Visual Pinball eller av PinReady. När det finns en visas en uppdateringsknapp i startaren: ett klick laddar ner och installerar den.

Bygg från källkod

PinReady är skrivet i Rust. På Linux (Debian eller Ubuntu) installerar du först byggverktygen:

sudo apt install build-essential cmake pkg-config \
  libxcb-render0-dev libxcb-shape0-dev libxcb-xfixes0-dev \
  libxkbcommon-dev libssl-dev

cargo build --release

På macOS och Windows räcker cargo build --release. SDL3 och SQLite kompileras automatiskt från källkod. Programmet hamnar i target/release/.
