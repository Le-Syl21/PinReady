问与答

关于 PinReady 和 Visual Pinball X 10.8.1 standalone 的常见问题。缺了什么？欢迎到 Discord 提问。

PinReady 适合我的机柜吗？

PinReady 旨在支持 Visual Pinball X 10.8.1 的开发与推广。它面向新 10.8.1 架构的测试者和尝鲜用户：内置插件、每张table一个文件夹、SDL3/bgfx 引擎。如果你的机柜运行的是你所依赖的稳定 VPX 10.7.x 环境，PinReady 目前可能还不适合你。

我需要一台真正的弹珠台机柜吗？

不需要。向导从一块屏幕开始：普通电脑请选择 1 块屏幕和桌面显示模式，用键盘或游戏手柄游玩。两到四块屏幕、弹珠台控制板、加速度计和环绕声都是可选的。

PinReady 会安装官方的 Visual Pinball 吗？

不会。自动安装会从 Le-Syl21/vpinball 下载一个近期的、经过 PinReady 测试的 Visual Pinball X 分支版本，而不是官方的 VPX 版本。如果你更想用自己安装的版本，请在第一页选择我已有 Visual Pinball，并让 PinReady 指向 VPinballX_BGFX 程序。

识别哪些弹珠台控制板？

Pinscape KL25Z（KL Shield V5.1、Brain、Rig Master）、Pinscape Pico、DudesCab 和 CSD PinOne。检测到其中之一时，它的出厂按钮布局会填入摇杆列，VPX 会自行处理 plunger 和加速度计。其他任何摇杆或游戏手柄也都能用：逐个映射它的按钮即可。参见向导的“输入”页面。

老table在 VPX standalone 下无法运行，怎么办？

一些老table使用了只能在 Windows 上运行的 VBScript 功能。在table页面中，打开自动 VBS 补丁：当 Le-Syl21/vpx-standalone-scripts 有对应补丁时，PinReady 会把打过补丁的脚本放在table旁边。它默认关闭，因为补丁偶尔会让某张特定的table变得更糟。你也可以手动操作：从 jsm174/vpx-standalone-scripts 取得与你的table相匹配的 .vbs，放在 .vpx 旁边，并使用相同的基本文件名。

如何为某一张table使用不同的设置？

在 .vpx 旁边放一个 .ini 文件，使用相同的基本文件名，里面只写你想更改的设置；其余全部来自全局的 VPinballX.ini。若想把这些设置保存在table文件本身里，vpxtool 可以解包table（vpxtool extract MyTable.vpx），再把 ini 放进去重新组装（vpxtool assemble MyTable/）。

我的table占用大量磁盘空间。

table往往带有很大的无损图片。vpxtool 可以把它们转换为 WebP：vpxtool images webp MyTable.vpx。

我的玩具、灯光和电磁铁在游戏中毫无反应。

Visual Pinball 出厂时关闭了所有插件，包括 DOF。请用 VPUniverse ConfigTool 生成你的 DOF 配置，把它解压到 directoutputconfig 文件夹，然后在配件页面打开 DOF。

table无缘无故 tilt，或者从不 tilt。

请检查 Tilt / Nudge 页面上的加速度计量程。它必须与你的板子实际使用的量程一致：如果板子公布了量程，PinReady 会从板上读取，所选值不匹配时会提醒你。量程错误会让每次摇晃看起来太强或太弱，其他任何设置都无法弥补。当所选的 tilt 角度超出传感器范围时，该页面也会告诉你。

声音从错误的扬声器发出。

请使用音频页面上的测试。如果滚动的球在前后方向上走错了，请更改输出模式；如果在左右方向上走错了，请检查左右接线。不同声卡的插孔颜色各不相同。

Linux：在配件页面找不到我的输出板。

在 Linux 上直接访问原始 USB HID 通常需要一条 udev 规则。配件页面会显示这些规则，可以复制，或在询问你的密码后替你安装。

Linux：在 Wayland 和 X11 之间切换后，需要重新运行向导吗？

不需要。同一块屏幕在 Visual Pinball 运行于 Wayland 还是 X11 下，名称并不相同，所以 PinReady 会按位置、尺寸和 EDID 身份（显示器报告的 ID）来记住每块屏幕。启动器启动时，它会选出 VPX 将使用的驱动，并更新 VPinballX.ini 中的屏幕名称使之匹配。

如何重新开始配置？

通过启动器的配置按钮打开向导，或运行 pinready --config。若要从头开始，请使用向导中的重置配置：它会忘记所有回答，并把你旧的 VPinballX.ini 保留为 VPinballX.ini.reset-backup。你的table不受影响。

Visual Pinball 崩溃了，怎么报告？

当 VPX 异常退出时，PinReady 会显示一份报告，包含重现崩溃的命令、系统信息、日志以及崩溃转储的位置。点击复制或保存…，然后分享到 Discord 或 GitHub issues。

table在启动器中显示“无图片”。

在table文件夹的 medias/launcher.png 放一张图片（.webp、.jpg 和 .jpeg 也可以），或放一个 .directb2s backglass 文件。如果你整理了table后图片看起来已过时，请在启动器中点击重建。

我的设置存放在哪里？

参见文件位置。pinready --print-paths 会打印 PinReady 实际使用的路径。
