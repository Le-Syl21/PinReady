table启动器

向导完成后，PinReady 会直接打开你的table：选一张，启动它，Visual Pinball 关闭后再回到列表。

浏览你的table

  • 以网格显示在你的table目录中找到的每个table文件夹，每个都带有它的 backglass 图片：取自该table的 .directb2s 文件、目录丰富功能下载的美术图，或你自己的 medias/launcher.png。
  • 搜索：直接开始输入，列表会随着输入实时筛选。
  • 在 Virtual Pinball Spreadsheet 中列有更新版本的table上会显示有可用更新徽章，如果你开启了 VPinPlay，还会显示社区评分。两者都会在扫描进行时出现，无需重启，table数据库会在启动时以及每六小时自动刷新。
  • 重建会清除缓存的图片和脚本补丁状态，然后重新扫描table文件夹，适用于列表与你的磁盘不再一致的情况。
  • 工具栏上还有用于重新打开向导的配置按钮、浅色/深色主题切换、旋转按钮和“关于”对话框。

在多屏机柜上

在机台显示模式下，启动器会在 playfield 屏幕上全屏打开，并旋转以适配平放的屏幕，鼠标指针由 PinReady 绘制。其他屏幕也会被用到：

  • Backglass：所选table的 backglass 图片。
  • DMD 和 topper：带有 Visual Pinball 标志和所选table详细信息的封面：名称、制造商和年份、作者、版本、日期、你玩过的次数以及你的评分。

table启动时，这些封面会让开，以便 Visual Pinball 接管所有屏幕。

启动table

加载table时，加载浮层会显示 Visual Pinball 报告的进度。在 Linux 上，PinReady 会根据你的桌面会话选择 Visual Pinball 运行所用的显示驱动（Wayland 或 X11），并同步更新 VPinballX.ini 中的屏幕名称，让每个窗口都在正确的屏幕上打开。

Visual Pinball 崩溃时

如果 Visual Pinball 异常退出，PinReady 不会悄悄回到列表，而是显示一份报告：重现问题的命令、工作文件夹、系统信息、加载日志、游戏日志的最后 100 行，以及崩溃转储在你系统上的确切位置（Linux 上是 systemd-coredump，macOS 上是 ~/Library/Logs/DiagnosticReports/，Windows 上是 %LOCALAPPDATA%\CrashDumps\）。复制会把它放到剪贴板，方便用于错误报告；保存…会把它写入文件。

Uppdateringar

PinReady 会在启动时检查 Visual Pinball 和它自身的新版本；启动器中会出现更新按钮，一键即可安装。首次启动时，它会在设置开始之前先提供较新的 PinReady，这样你就能用最新的修复来完成全部设置。重置配置会保留你的 Visual Pinball 安装，因此不会为你已有的版本提示更新。

命令行选项

选项作用
--config, -c打开设置向导。
--reset-wizard把向导标记为未完成并退出：下次启动会回到向导。
--merge-dry-run SCAN_ROOT [OUTPUT] [--strategy MODE]显示集合导入会放置哪些内容，而不触碰任何文件。
--merge SCAN_ROOT [OUTPUT] [--strategy MODE] [--yes]运行导入。MODE 可以是 copy（默认）、move 或 symlink；当集合已经是每张table一个文件夹时，可省略 OUTPUT。
--print-paths打印数据库、日志、ini、table和 Visual Pinball 的路径。
--list-tables为找到的每个table文件夹打印一行。
--version, --help显示版本和许可证，或帮助信息。
