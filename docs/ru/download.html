Скачать PinReady

PinReady — это один исполняемый файл: скачайте версию для вашей системы, распакуйте и запустите. Ничего устанавливать не нужно. Эти ссылки всегда ведут на последний релиз.

Запуск

  • Windows: распакуйте zip-архив, затем дважды щёлкните pinready.exe.
  • Linux: распакуйте архив и запустите программу из её папки: 
    tar xzf pinready-linux-x86_64.tar.gz ./pinready
  • macOS: распакуйте архив и запустите программу из Терминала: 
    tar xzf pinready-macos-aarch64.tar.gz ./pinready

Программа для Windows имеет цифровую подпись, а программы для macOS подписаны и нотаризованы Apple. Сборки для macOS рассчитаны на macOS 11 или новее.

При первом запуске открывается мастер настройки, при следующих — лаунчер столов.

Что вам понадобится

  • Visual Pinball X 10.8.1 или новее. PinReady может установить его за вас или использовать копию, которую вы установили сами.
  • Папка со столами в формате 10.8.1: одна папка на стол. PinReady поможет её подготовить: см. страницу «Столы» мастера.
  • Подключение к Интернету для автоматической установки Visual Pinball и проверки обновлений. Если вы устанавливаете Visual Pinball сами, оно не обязательно.

Устанавливать библиотеки не нужно: SDL3 и SQLite встроены в PinReady.

Установка Visual Pinball

На первой странице мастера есть два варианта:

  • Установить автоматически (рекомендуется) — скачивает и устанавливает свежую сборку форка Visual Pinball X, проверенного с PinReady, из Le-Syl21/vpinball. Это не официальная сборка VPX. Она подбирает сборку под вашу систему, включая сборки для плат Raspberry Pi и RK3588 на ARM Linux. Папку установки выбираете вы.
  • У меня уже есть Visual Pinball — используется копия, которую вы установили сами: укажите PinReady программу VPinballX_BGFX.

Автоматическая установка проверена на Ubuntu 24.04 и 26.04 LTS (GNOME) и на Windows 11 с 4 экранами. Официальный проект Visual Pinball находится по адресу vpinball/vpinball.

Обновления

При запуске PinReady проверяет, не вышла ли новая сборка Visual Pinball или новая версия PinReady. Если вышла, в лаунчере появляется кнопка обновления: один щелчок — и она скачивается и устанавливается.

Сборка из исходников

PinReady написан на Rust. В Linux (Debian или Ubuntu) сначала установите инструменты сборки:

sudo apt install build-essential cmake pkg-config \
  libxcb-render0-dev libxcb-shape0-dev libxcb-xfixes0-dev \
  libxkbcommon-dev libssl-dev

cargo build --release

На macOS и Windows достаточно cargo build --release. SDL3 и SQLite автоматически собираются из исходников. Готовая программа окажется в target/release/.
