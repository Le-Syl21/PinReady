Télécharger PinReady

PinReady tient en un seul fichier programme : téléchargez celui de votre système, décompressez-le et lancez-le. Il n'y a rien à installer. Ces liens mènent toujours à la dernière version.

Le lancer

  • Windows : décompressez le zip, puis double-cliquez sur pinready.exe.
  • Linux : décompressez l'archive et lancez le programme depuis son dossier : 
    tar xzf pinready-linux-x86_64.tar.gz
./pinready
  • macOS : décompressez l'archive et lancez le programme depuis le Terminal : 
    tar xzf pinready-macos-aarch64.tar.gz
./pinready

Le programme Windows est signé numériquement, et les programmes macOS sont signés et notariés auprès d'Apple. Les versions macOS visent macOS 11 ou plus récent.

Le premier lancement ouvre l'assistant de configuration ; les suivants ouvrent le lanceur de tables.

Ce qu'il faut

  • Visual Pinball X 10.8.1 ou plus récent. PinReady peut l'installer pour vous, ou utiliser une copie que vous avez installée vous-même.
  • Un dossier de tables au format 10.8.1, un dossier par table. PinReady peut vous aider à y arriver : voir la page Tables de l'assistant.
  • Une connexion Internet pour l'installation automatique de Visual Pinball et la recherche de mises à jour. Elle est facultative si vous installez Visual Pinball vous-même.

Aucune bibliothèque à installer : SDL3 et SQLite sont intégrés à PinReady.

Installer Visual Pinball

La première page de l'assistant propose deux choix :

  • Installer automatiquement (recommandé) télécharge et installe une version récente du fork de Visual Pinball X validé avec PinReady, depuis Le-Syl21/vpinball. Ce n'est pas la version officielle de VPX. La version adaptée à votre système est choisie automatiquement, y compris pour les cartes Raspberry Pi et RK3588 sous Linux ARM. Vous choisissez le dossier d'installation.
  • J'ai déjà Visual Pinball utilise une copie installée par vos soins : indiquez à PinReady le programme VPinballX_BGFX.

L'installation automatique est validée sous Ubuntu 24.04 LTS, en X11, sur un pincab à 3 écrans. Le projet officiel Visual Pinball se trouve sur vpinball/vpinball.

Mises à jour

Au démarrage, PinReady vérifie si une nouvelle version de Visual Pinball ou de PinReady est sortie. Si c'est le cas, un bouton de mise à jour apparaît dans le lanceur : un clic la télécharge et l'installe.

Compiler depuis les sources

PinReady est écrit en Rust. Sous Linux (Debian ou Ubuntu), installez d'abord les outils de compilation :

sudo apt install build-essential cmake pkg-config \
  libxcb-render0-dev libxcb-shape0-dev libxcb-xfixes0-dev \
  libxkbcommon-dev libssl-dev

cargo build --release

Sous macOS et Windows, cargo build --release suffit. SDL3 et SQLite sont compilés depuis les sources automatiquement. Le programme se trouve ensuite dans target/release/.
