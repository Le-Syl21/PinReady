Questions et réponses

Les questions fréquentes sur PinReady et Visual Pinball X 10.8.1 standalone. Il en manque une ? Posez-la sur Discord.

PinReady est-il fait pour mon flipper ?

PinReady est conçu pour accompagner le développement et l'adoption de Visual Pinball X 10.8.1. Il s'adresse aux testeurs et aux premiers utilisateurs de la nouvelle architecture 10.8.1 : plugins intégrés, un dossier par table, moteur SDL3/bgfx. Si votre flipper tourne sur une installation VPX 10.7.x stable dont vous dépendez, PinReady n'est probablement pas encore pour vous.

Faut-il un vrai meuble de flipper ?

Non. L'assistant part d'un seul écran : choisissez 1 écran et le mode d'affichage Bureau pour un ordinateur classique, et jouez au clavier ou à la manette. De deux à quatre écrans, les cartes de contrôleur de flipper, l'accéléromètre et le son surround sont tous facultatifs.

PinReady installe-t-il le Visual Pinball officiel ?

Non. L'installation automatique télécharge une version récente du fork de Visual Pinball X validé avec PinReady, depuis Le-Syl21/vpinball, et non la version officielle de VPX. Si vous préférez votre propre installation, choisissez J'ai déjà Visual Pinball sur la première page et indiquez le programme VPinballX_BGFX.

Quelles cartes de contrôleur de flipper sont reconnues ?

Pinscape KL25Z (KL Shield V5.1, Brain, Rig Master), Pinscape Pico, DudesCab et CSD PinOne. Quand l'une d'elles est détectée, sa disposition de boutons d'usine remplit la colonne Joystick, et VPX gère lui-même le lanceur de bille (plunger) et l'accéléromètre. Tout autre joystick ou manette fonctionne aussi : assignez ses boutons un par un. Voir la page Inputs de l'assistant.

Une ancienne table ne fonctionne pas sous VPX standalone. Que faire ?

Certaines anciennes tables utilisent des fonctions VBScript qui n'existent que sous Windows. Sur la page Tables, activez les patches VBS automatiques : PinReady place alors un script corrigé à côté de la table quand Le-Syl21/vpx-standalone-scripts en propose un. L'option est désactivée par défaut, car un patch peut parfois dégrader une table précise. Vous pouvez aussi le faire à la main : prenez le .vbs de votre table dans jsm174/vpx-standalone-scripts et posez-le à côté du .vpx, avec le même nom de base.

Comment régler une table différemment des autres ?

Posez un fichier .ini à côté du .vpx, avec le même nom de base, qui ne contient que les réglages à changer ; tout le reste vient du VPinballX.ini global. Pour garder ces réglages dans le fichier de la table, vpxtool peut extraire la table (vpxtool extract MaTable.vpx) puis la réassembler avec l'ini à l'intérieur (vpxtool assemble MaTable/).

Mes tables prennent beaucoup de place.

Les tables contiennent souvent de grosses images sans perte. vpxtool sait les convertir en WebP : vpxtool images webp MaTable.vpx.

Mes jouets, lumières et solénoïdes ne réagissent pas en jeu.

Visual Pinball est livré avec tous ses plugins désactivés, DOF compris. Générez votre configuration DOF avec le ConfigTool de VPUniverse, décompressez-la dans le dossier directoutputconfig, puis activez DOF depuis la page Accessoires.

La table tilte pour rien, ou ne tilte jamais.

Vérifiez la plage de l'accéléromètre sur la page Tilt / Nudge. Elle doit correspondre à la plage réellement utilisée par votre carte : PinReady la lit sur la carte quand celle-ci la publie, et vous prévient si la valeur choisie ne correspond pas. Une mauvaise plage fait paraître chaque secousse trop forte ou trop faible, et aucun autre réglage ne peut compenser. La page indique aussi quand l'angle de tilt choisi est hors de portée du capteur.

Le son sort des mauvaises enceintes.

Servez-vous des tests de la page Audio. Si la bille qui roule va dans le mauvais sens d'avant en arrière, changez le mode de sortie ; si elle va dans le mauvais sens de gauche à droite, vérifiez le câblage gauche/droite. Les couleurs des prises varient d'une carte son à l'autre.

Linux : ma carte de sorties n'est pas trouvée sur la page Accessoires.

Sous Linux, l'accès USB HID direct demande en général une règle udev. La page Accessoires affiche ces règles, peut les copier, ou les installer pour vous après avoir demandé votre mot de passe.

Linux : faut-il relancer l'assistant après être passé de Wayland à X11 ?

Non. Un même écran porte un nom différent selon que Visual Pinball tourne sous Wayland ou sous X11 ; PinReady retient donc chaque écran par sa position, sa taille et son identité EDID (l'identifiant que l'écran transmet). Au démarrage du lanceur, il choisit le pilote que VPX utilisera et met à jour les noms d'écran dans VPinballX.ini en conséquence.

Comment refaire la configuration ?

Ouvrez l'assistant avec le bouton Config du lanceur, ou lancez pinready --config. Pour repartir de zéro, utilisez Réinitialiser la configuration dans l'assistant : il oublie toutes les réponses et garde votre ancien VPinballX.ini sous le nom VPinballX.ini.reset-backup. Vos tables ne sont pas touchées.

Visual Pinball a planté. Comment le signaler ?

Quand VPX se ferme anormalement, PinReady affiche un rapport avec la commande pour reproduire le plantage, les informations système, les journaux et l'emplacement du fichier de plantage. Cliquez sur Copier ou Enregistrer… et partagez-le sur Discord ou dans les tickets GitHub.

Une table affiche « pas d'image » dans le lanceur.

Déposez une image medias/launcher.png dans le dossier de la table (.webp, .jpg et .jpeg fonctionnent aussi), ou un fichier de fronton .directb2s. Si les images semblent périmées après une réorganisation de vos tables, cliquez sur Reconstruire dans le lanceur.

Où sont enregistrés mes réglages ?

Voir les emplacements des fichiers. pinready --print-paths affiche les chemins réellement utilisés par PinReady.
