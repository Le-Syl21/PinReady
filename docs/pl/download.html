Pobierz PinReady

PinReady to pojedynczy plik programu: pobierz wersję dla swojego systemu, rozpakuj i uruchom. Nic nie trzeba instalować. Te odnośniki zawsze prowadzą do najnowszego wydania.

Informacje o wydaniach i starsze wersje: wszystkie wydania na GitHubie.

Uruchomienie

  • Windows: rozpakuj plik zip, a następnie kliknij dwukrotnie pinready.exe.
  • Linux: rozpakuj archiwum i uruchom program z jego folderu: 
    tar xzf pinready-linux-x86_64.tar.gz ./pinready
  • macOS: rozpakuj archiwum i uruchom program w Terminalu: 
    tar xzf pinready-macos-aarch64.tar.gz ./pinready

Program dla Windows jest podpisany cyfrowo, a programy dla macOS są podpisane i notaryzowane przez Apple. Wersje dla macOS są przeznaczone dla macOS 11 lub nowszego.

Pierwsze uruchomienie otwiera kreator konfiguracji, kolejne otwierają launcher stołów.

Czego potrzebujesz

  • Visual Pinball X 10.8.1 lub nowszy. PinReady może go dla Ciebie zainstalować albo użyć kopii, którą zainstalowałeś(-aś) samodzielnie.
  • Folder ze stołami w układzie 10.8.1, czyli jeden folder na stół. PinReady pomoże Ci do niego dojść: zobacz stronę Stoły w kreatorze.
  • Połączenie z Internetem do automatycznej instalacji Visual Pinball i sprawdzania aktualizacji. Jest opcjonalne, jeśli instalujesz Visual Pinball samodzielnie.

Nie trzeba instalować żadnych bibliotek: SDL3 i SQLite są wbudowane w PinReady.

Instalacja Visual Pinball

Pierwsza strona kreatora oferuje dwie możliwości:

  • Zainstaluj automatycznie (zalecane) pobiera i instaluje aktualną wersję forka Visual Pinball X testowanego z PinReady, z Le-Syl21/vpinball. To nie jest oficjalna wersja VPX. Wybiera wersję dla Twojego systemu, w tym wersje dla Raspberry Pi i płytek RK3588 na Linuxie ARM. Folder instalacji wybierasz Ty.
  • Mam już Visual Pinball używa kopii zainstalowanej przez Ciebie: wskaż PinReady program VPinballX_BGFX.

Instalacja automatyczna była testowana na Ubuntu 24.04 i 26.04 LTS (GNOME) oraz na Windows 11, z 4 ekranami. Oficjalny projekt Visual Pinball znajdziesz pod adresem vpinball/vpinball.

Aktualizacje

Przy starcie PinReady sprawdza, czy pojawiła się nowa wersja Visual Pinball lub nowa wersja PinReady. Gdy tak, w launcherze pojawia się przycisk aktualizacji: jedno kliknięcie pobiera i instaluje ją.

Kompilacja ze źródeł

PinReady jest napisany w Rust. Na Linuxie (Debian lub Ubuntu) najpierw zainstaluj narzędzia do kompilacji:

sudo apt install build-essential cmake pkg-config \
  libxcb-render0-dev libxcb-shape0-dev libxcb-xfixes0-dev \
  libxkbcommon-dev libssl-dev

cargo build --release

Na macOS i Windows wystarczy cargo build --release. SDL3 i SQLite są kompilowane automatycznie ze źródeł. Program trafia do target/release/.
