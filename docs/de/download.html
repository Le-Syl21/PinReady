PinReady herunterladen

PinReady ist eine einzige Programmdatei: Lade die für dein System herunter, entpacke sie und starte sie. Es muss nichts installiert werden. Diese Links zeigen immer auf die neueste Version.

Versionshinweise und ältere Versionen: alle Releases auf GitHub.

Starten

  • Windows: Entpacke die Zip-Datei und doppelklicke dann auf pinready.exe.
  • Linux: Entpacke das Archiv und starte das Programm aus seinem Ordner: 
    tar xzf pinready-linux-x86_64.tar.gz ./pinready
  • macOS: Entpacke das Archiv und starte das Programm im Terminal: 
    tar xzf pinready-macos-aarch64.tar.gz ./pinready

Das Windows-Programm ist digital signiert, die macOS-Programme sind signiert und von Apple notariell beglaubigt. Die macOS-Versionen setzen macOS 11 oder neuer voraus.

Beim ersten Start öffnet sich der Einrichtungsassistent, bei den folgenden Starts der Tisch-Launcher.

Was du brauchst

  • Visual Pinball X 10.8.1 oder neuer. PinReady kann es für dich installieren oder eine selbst installierte Kopie verwenden.
  • Einen Tischordner im 10.8.1-Aufbau, ein Ordner pro Tisch. PinReady hilft dir dabei: siehe die Seite Tische des Assistenten.
  • Eine Internetverbindung für die automatische Installation von Visual Pinball und die Update-Prüfung. Sie ist optional, wenn du Visual Pinball selbst installierst.

Es müssen keine Bibliotheken installiert werden: SDL3 und SQLite sind in PinReady eingebaut.

Visual Pinball installieren

Die erste Seite des Assistenten bietet zwei Möglichkeiten:

  • Automatisch installieren (empfohlen) lädt eine aktuelle Version des mit PinReady getesteten Visual-Pinball-X-Forks von Le-Syl21/vpinball herunter und installiert sie. Das ist nicht die offizielle VPX-Version. Es wählt die passende Version für dein System, auch Versionen für Raspberry Pi und RK3588-Boards unter ARM-Linux. Den Installationsordner wählst du selbst.
  • Ich habe Visual Pinball bereits verwendet eine selbst installierte Kopie: Zeige PinReady das Programm VPinballX_BGFX.

Die automatische Installation ist unter Ubuntu 24.04 und 26.04 LTS (GNOME) sowie unter Windows 11 mit 4 Bildschirmen getestet. Das offizielle Visual-Pinball-Projekt findest du unter vpinball/vpinball.

Updates

Beim Start prüft PinReady, ob es eine neue Version von Visual Pinball oder von PinReady gibt. Ist eine da, erscheint im Launcher eine Update-Schaltfläche: Ein Klick lädt sie herunter und installiert sie.

Aus dem Quellcode bauen

PinReady ist in Rust geschrieben. Unter Linux (Debian oder Ubuntu) installierst du zuerst die Build-Werkzeuge:

sudo apt install build-essential cmake pkg-config \
  libxcb-render0-dev libxcb-shape0-dev libxcb-xfixes0-dev \
  libxkbcommon-dev libssl-dev

cargo build --release

Unter macOS und Windows genügt cargo build --release. SDL3 und SQLite werden automatisch aus dem Quellcode kompiliert. Das Programm landet in target/release/.
